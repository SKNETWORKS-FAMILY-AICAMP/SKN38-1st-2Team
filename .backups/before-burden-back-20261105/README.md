# 전기차 인프라 SVG 지도

Python 3.10 이상. 프로젝트 폴더에서 실행:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 사용법

- 시도 → 시군구 → 충전소 마커 순으로 선택합니다. 전국에서 시도 진입은 경계의 모양을 유지하며 720ms 동안 확대됩니다. 상단 경로로 상위 단계로 돌아갑니다.
- 구 선택 시 해당 구로 부드럽게 확대합니다. 구의 가장 긴 변 기준으로 양쪽 28% 여백을 두어 주변 구가 가장자리에 일부 보이도록 합니다. 해당 시도의 모든 시군구와 외곽선 도형은 유지하되, 확대된 표시 범위 밖은 자연스럽게 잘립니다. 선택 구만 원래 부담도 색상과 강조 테두리로 표시하고 다른 구는 옅게 표시합니다. 보이는 옆 구를 직접 누르면 그 구로 확대·이동하고 선택·통계·마커가 바뀌며 이전 충전소 상세는 닫힙니다.
- 마커 또는 검색·즐겨찾기에서 충전소를 선택하면 지도가 왼쪽 약 65%, 상세정보가 오른쪽 약 35%로 0.32초 동안 전환됩니다. 닫기 버튼으로 원래 지도 너비를 복원합니다. 좁은 모바일 화면은 오른쪽에서 들어오는 겹침 패널을 사용합니다.
- 패널이 열려 지도가 좁아져도 선택 구와 주변 여백을 유지합니다. 주소는 지도 위 고정 크기 라벨과 우측 상세에서 표시하며, 복사 버튼도 제공합니다. 복사 권한이 제한되면 주소 텍스트를 선택하고 수동 복사를 안내합니다.
- 화면에서 25px 안에 가까운 마커를 묶어 개수로 표시합니다. 묶음을 누르면 우측 목록에서 개별 충전소를 선택할 수 있습니다. 지도 아래 충전소 목록으로도 직접 선택할 수 있습니다.
- 휠·드래그·확대 버튼은 없으며 외부 지도 타일도 사용하지 않습니다.
- 위쪽 검색창에서 지역명, 도로명주소, 충전소명을 부분 검색합니다. 지역 결과가 먼저 나오고 이름 기준 가나다순, 동명 지역은 시도명 순으로 정렬됩니다. 방향키와 Enter, Escape도 지원합니다.
- 지역의 `☆ 현재 지역 저장` 또는 충전소 상세의 `☆ 즐겨찾기`로 별명을 지정합니다. 왼쪽 즐겨찾기를 누르면 해당 지역/충전소로 바로 이동합니다. 별명 수정과 삭제도 지원합니다.
- 즐겨찾기는 브라우저 localStorage에 저장됩니다. 같은 브라우저·접속 주소(호스트와 포트)에서 유지되며 계정이나 다른 기기에 동기화하지 않습니다. 저장소가 제한되면 현재 화면에서만 유지된다는 안내가 나옵니다.
- 작은 모바일 화면에서는 즐겨찾기가 지도 아래로 이동합니다.

## 구조

`app.py`는 초기 데이터만 준비합니다. 지도 전환·검색·즐겨찾기·상세 선택은 `components/map_view.js`에서 처리하여 클릭할 때마다 Python을 재실행하지 않습니다. 모든 지도 path와 마커가 같은 Mercator 좌표계에 있으므로 도형을 바꾸지 않고 SVG viewBox만 보간하여 확대합니다. 시도 진입 시에는 시도 전체 범위에 맞추고, 구 선택 시에는 구 경계와 28% 주변 여백에 맞춥니다. 주변 구 path를 숨기지 않아 일부 보이는 옆 구를 계속 클릭할 수 있습니다. ResizeObserver로 라벨·마커의 화면 크기와 묶음을 재계산합니다. 키보드 접근과 `prefers-reduced-motion`을 지원합니다.

- `map_assets.py`: GeoJSON → SVG path 사전 변환. 경계를 바꾼 뒤 `python map_assets.py`로 재생성합니다.
- `assets/maps.json`: 앱이 사용하는 SVG path, 경계 범위, 행정코드.
- `assets/maps/korea.svg`, `sido_*.svg`: 독립적으로 재사용할 수 있는 전국·17개 시도 SVG.
- `components/map_view.html`, `.css`, `.js`: 브라우저 화면.
- `data_provider.py`: 기존 샘플/API/DB 교체 지점.
- `data/raw_station_sample.json`: 사용자가 제공한 낙성대동주민센터 API 예시.
- 기존 `data/*.csv`: 가상 지역 통계·충전소 데이터.

샘플 집계 수치는 충전소 상세 표본 전체의 합과 일치하도록 만든 실측 통계가 아닙니다. 모든 차량·충전기 집계는 가상이며 전기이륜차를 제외합니다. 제공 API 예시의 상태는 실시간이 아니며 코드 원문을 표시합니다.

## 실제 데이터 교체

`app.py`의 `SampleCsvProvider`를 `EVDataProvider` 구현으로 교체하세요. 충전소의 `station_id`, `sigungu_code`, `station_name`, `address`, `lat`, `lng`를 필수로 유지하면 주소 검색·즐겨찾기 이동이 연결됩니다. 도로명주소는 원문으로 보존하세요. API의 `statId` 단위로 충전소를 구성하고, 다수 `chgerId` 행은 수집 단계에서 충전소별로 집계해야 합니다. 같은 좌표에 여러 충전소가 있으면 지도 아래 충전소 목록으로도 선택할 수 있습니다.

이 버전은 초기 로딩한 데이터 스냅샷을 사용합니다. 새 데이터 반영 시 앱 캐시를 지우거나 서버를 재시작하세요. 실시간 상세 API 연결은 별도 제공자에서 구현해야 합니다. 미확인 좌표와 지역 코드가 있는 데이터는 적재 전에 정리하세요.

## 경계 출처

국가공간정보포털(V-World) 2023-07-29 원본을 WGS84로 가공한 공개 GeoJSON. 17개 시도, 250개 시군구인 해당 배포본을 사용하며 최신 행정구역을 보장하지 않습니다.

가공/배포: https://github.com/KnellBalm/kr-admin-geojson

## 확인

```powershell
python -m py_compile app.py map_assets.py
```

브라우저에서 전국/시도/시군구 클릭, `강` 자동완성 순서, 서울·부산 강서구 구분, `낙성대로` 도로명 검색, 우측 상세 패널/닫기, 지도 위 주소, 묶음 목록, 별명 저장·수정 및 새로고침 후 즐겨찾기 복원을 확인하세요. 서울에서 관악구 선택 시 실제 viewBox가 작아져 확대되는지, 가장자리에 동작구 등이 일부 보이는지 확인하세요. 보이는 동작구 경계를 직접 눌러 해당 구로 확대·이동하며 마커·통계가 교체되고 이전 상세 패널이 닫히는지도 확인하세요.
