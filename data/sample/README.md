# 실데이터 표본

로컬 MySQL `ev_infra`의 적재본에서 읽기 전용으로 추출한 UTF-8 CSV입니다. 지도 시연용 가상 데이터와 주소 검색 예시는 [`../demo`](../demo/)에 있습니다.

| 파일 | 행 수 | 범위와 선택 기준 |
|---|---:|---|
| `charging_station.csv` | 20 | 서울 강서구·관악구·송파구, 부산 강서구, 제주 제주시에서 각각 4곳입니다. 지도 매핑이 완료된 곳 중 이용제한 없는 활성 충전기가 있는 충전소를 선정했고, 주소 검색 예시인 `ME174013`을 포함했습니다. |
| `charger.csv` | 71 | 위 충전소에서 삭제 상태가 아닌 충전기입니다. 이용제한 여부와 정격출력을 보존했습니다. |
| `charger_status_latest.csv` | 71 | 표본 충전기와 같은 `stat_id + chger_id`의 적재 시점 상태입니다. |
| `cafe.csv` | 15 | 서울·부산·제주의 좌표 범위에서 각각 5곳을 추출했습니다. |
| `ev_passenger_monthly.csv` | 12 | 2025년 10월~2026년 9월 전국 비사업용 승용차 등록통계입니다. |
| `ev_sido_monthly.csv` | 201 | 같은 기간의 시도별 전기차 등록대수입니다. 전남광주 합산 원본을 유지했습니다. |

ID와 지역코드는 문자로 취급합니다. 예를 들어 `chger_id`의 `01`을 숫자 `1`로 변환하면 상태 테이블과 연결할 때 키가 달라집니다. `stat_id`와 `chger_id`로 조인하며, 충전기 상태는 실시간 조회 결과로 해석하지 않습니다. 표본에는 원본 JSON과 연락처 컬럼을 제외했습니다.
